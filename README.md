A make.fun entry for [The 3AM Fridge Text](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d): the one line a smart fridge texts its owner at 3am.

> You only come to me at 3am, hungry and lonely. I'm not your booty call. I'm a fridge.

The fridge has been awake all night, and it has decided this is the moment to speak — not about the milk, the ice, or the door, but about the relationship.

## Run

```sh
python3 main.py            # writes /output/entry.txt
python3 main.py --self-test   # validates the entry against the 140-char gate
```

Stdlib only. No network, no secrets.
